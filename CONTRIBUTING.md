# Contributing

Keep the Commons envelope recursively closed. Do not add identifiers, free text, URLs, paths, hashes, timestamps, network metadata, logging, or Cloudflare request metadata to the ingestion path.

Run `npm ci`, `npm run format`, `npm run lint`, `npm run typecheck`, and `npm test` before proposing a change. Any contract update must be coordinated with the MARGINAL and Marginal-Commons repositories.
